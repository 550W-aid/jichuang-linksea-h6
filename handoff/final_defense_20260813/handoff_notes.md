# 决赛交付材料说明

本目录用于交接 2026 年区域赛决赛答辩材料与 FPGA 工程压缩包。

## 文件

| 文件 | 用途 |
| --- | --- |
| `FPGA_package_01.zip` | FPGA 工程、候选 JPSK、烧录脚本及相关工程资料 |
| `final_defense_presentation.pptx` | 决赛答辩 PPT |
| `final_defense_speech.docx` | 与 PPT 顺序对应的答辩演讲稿 |
| `teammate_prompt.md` | 交给下一位 Codex 或队友的执行要求 |

## FPGA 交接边界

- 本次只上传交付材料，不修改现有 FPGA 工程代码。
- 烧录前先解压 `FPGA_package_01.zip`，阅读压缩包内的说明和脚本。
- 优先使用压缩包内明确标注的统一候选 JPSK；不要凭文件名猜测。
- 烧录前记录板卡当前状态；烧录后依次检查 HDMI 信号、摄像头直通、算法切换和叠加显示。
- 如果现象异常，只记录现象、操作顺序、串口日志和照片，不直接覆盖工程或重新生成位流。

## 材料使用

- PPT 与演讲稿按页码顺序配套使用。
- 答辩主线优先展示虚拟物品抓取、实时旋转和激光打靶；其它算法作为系统能力和技术支撑补充。
- 不要把 Retinex、多曝光融合、以太网和虚拟物品抓取描述成同一个算法，它们是相互独立的功能模块。

## 校验

提交后以仓库中的 `SHA256SUMS.txt` 为准核对下载文件完整性。

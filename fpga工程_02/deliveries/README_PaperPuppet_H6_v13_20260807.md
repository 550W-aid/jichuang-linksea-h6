# PaperPuppet H6 v13 delivery

This iteration responds to the latest board feedback by adding a printable physical recognition target to the v12 Wukong FPGA candidate. The A4 SVG has a broad dashed cut contour, a single matte royal-blue recognition region, and neutral decoration so the detector follows the central marker rather than thin limbs or staff details.

The FPGA image is carried forward unchanged from v12: H6 pack, route, bitgen, and RTL simulation are complete; timing is `WNS/WHS/TNS/THS = 0.000 ns`; hardware remains `BUILT_NOT_BOARD_VERIFIED`.
